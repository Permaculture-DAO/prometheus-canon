# 6. Canon variants

Do **not** delete Canon variants merely from filename inference.

The Full Corpus itself states that its preserved complete corpus is subordinate to the authoritative Canon section above.

Until governance explicitly retires the separate `White_Paper.docx` and `White_Paper_Full.docx`, classify them as:

`REFERENCE / CANON PRESENTATION VARIANT`

rather than active competing authority.

# 7. Retrieval policy

Default AI retrieval should prefer:

`ACTIVE → ACTIVE_SUPPORTING`

and exclude:

`SUPERSEDED / HISTORICAL`

unless the task is provenance, diff, audit or decision history.

# 8. Project-source limitation

Project-attached sources cannot be programmatically detached by the available Files interface.

Therefore:

- authority is removed immediately through this Registry/Manifest;
- mutable Library duplicates can be moved to `/PROMETHEUS/Archive/Superseded/2026-10-07/`;
- Project UI detachment, if desired for visual cleanliness, remains a product-surface action and does not affect authority once the Root Manifest is adopted.

# 9. Migration acceptance

Migration passes when:

- only one ACTIVE global architecture exists;
- only one ACTIVE RAVEL operational source exists;
- only one ACTIVE Civilization source exists;
- duplicate imported copies are archived;
- all new active files have hashes;
- dependencies resolve;
- no active source points to PRM-ARCH-DET-001.
