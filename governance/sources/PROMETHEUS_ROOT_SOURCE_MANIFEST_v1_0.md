# 2. Precedence

**Factual → observed/verified evidence**  
**Constitutional → Canon**  
**Architecture generation → Architecture Meta-Layer**  
**Global architecture → PRM-ARCH-DET-002**  
**Method → registered methodology**  
**Application → active application source within scope**  
**Implementation → verified repository/runtime state within implementation scope**  
**Legal → law/competent authority/executed instrument within legal scope**.

# 3. D/P/H/Q

`D` deterministic verification governs state and gates.  
`P` probabilistic models quantify uncertainty.  
`H` heuristics/LLMs explore and propose.  
`Q` quantum/quantum-inspired computation remains research/shadow unless it beats a classical baseline.

**P/H/Q → D verification → human/domain authority → action.**
