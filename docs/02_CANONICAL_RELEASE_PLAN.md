# Canonical Release Plan — RC2 Strict

1. Confirm source DOCX.
2. Confirm table-complete Markdown derivative.
3. Review repository overlay for every current root `.md` file.
4. Confirm deprecated legacy documents are not treated as release-critical.
5. Run RC2 QA.
6. Freeze text.
7. Regenerate SHA-256.
8. Sign with maintainer GPG key.
9. Verify signatures.
10. Tag release candidate.
11. Publish GitHub release only after review.
